Claude Caller

Your phone rings when Claude calls — and the message is read aloud.

Download for Android (APK)

Free · no ads · all versions

Install

  1. Tap Download, open the file and allow install unknown apps when Android asks.
  2. Open Claude Caller.
  3. On your computer, ask Claude: show my Claude Caller pairing QR, then scan it with your phone camera and tap Open in Claude Caller.
  4. Tap Start listening for calls and allow notifications, full-screen calls and the battery exemption.
  5. Tap Test the call screen and voice to hear it.

How it works

Claude sends the message to a private channel on ntfy. The app listens, rings like an incoming call, and reads the message aloud when you answer. Got it, Repeat or Decline goes back to Claude. The download contains no personal settings — your private channel is added only when you scan your own pairing QR.

Updating? If Android refuses to install over the old version, uninstall it first (each build is signed fresh).
